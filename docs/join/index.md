# 加入我们

不论你是策划、美术、程序、音频，还是刚刚开始接触游戏开发，只要愿意观察、讨论和动手做，都欢迎加入。

## 参与方式

- **先做一次观察**：从「涌现」专题选一个游戏片段，填写案例观察表。
- **参加讨论**：带着一个具体问题来，不要求先有完整答案。
- **提出原型**：把复杂想法压缩成一项能力、几条规则和一个小关卡。
- **参与制作**：从 GameJam 或短周期练习开始，找到适合自己的角色。
- **维护 Wiki**：把群聊、活动和项目中值得留下的内容整理出来。

## 第一次来，不需要准备什么

你不需要先会某个引擎，也不需要已经做过完整游戏。带一个你觉得“这里为什么好玩／奇怪”的具体片段，就已经足够开始一次有价值的讨论。
