## 从能力与问题开始

分析一段玩法时，先问两个最朴素的问题：

1. 设计者给了玩家什么能力？
2. 关卡用什么情境或问题，让这种能力变得有意义？

随后再观察能力的规则、限制、变化，以及同一问题是否允许多种解法。当前「涌现」专题正用这套方法拆解案例。

## 内容索引

| 方向 | 关注的问题 |
| --- | --- |
| 玩法设计 | 玩家的行动、反馈和目标怎样形成核心循环？ |
| 关卡设计 | 如何教学、变化、组合并验证玩家已经掌握的能力？ |
| 系统设计 | 多个简单规则如何相互作用，产生复杂结果？ |
| 数值设计 | 数值如何表达节奏、风险、成长与选择？ |
| 叙事设计 | 叙事如何通过空间、规则与玩家行动发生？ |
