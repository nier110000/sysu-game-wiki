# 关于我们

我们是一群在中山大学学习、讨论并制作游戏的同学。有人关注策划和叙事，有人喜欢程序与工具，也有人研究视觉、动画和交互；共同点是愿意把一个模糊想法做成可以体验、可以讨论的东西。

## 我们在做什么

- 一起观察和拆解优秀游戏中的具体设计。
- 用分享会和讨论会交换方法与经验。
- 用短周期原型验证想法，而不只停留在概念。
- 参加 GameJam，完成作品并认真复盘。
- 把过程整理成公开 Wiki，让经验可以传下去。

## 为什么做 Wiki

群聊很适合产生想法，却不适合长期检索。腾讯文档负责低门槛协作，Wiki 负责整理和沉淀：让后来加入的人可以理解我们研究过什么、做过什么，以及下一步还能从哪里继续。
