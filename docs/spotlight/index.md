# 聚光灯 GameJam「涌现」

<span class="tag">当前专题</span><span class="tag">案例研究</span><span class="tag">2D 原型</span><span class="tag">GameJam</span>

这次专题研究的不是某一种固定玩法，而是一个设计问题：**当少量清晰的规则彼此组合时，怎样让玩家发现设计者没有逐条规定的解法？**

<div class="flowline">
观察具体片段 → 描述玩家能力 → 拆解规则与限制 → 分析关卡问题 → 比较不同解法 → 提炼可用规律 → 做成小型 2D 原型
</div>

## 01 · 我们在研究什么？

我们把“涌现”暂时理解为：简单的对象、能力和环境规则经过组合，产生丰富、可推演、甚至出乎预期的结果。重点不是系统越多越好，而是每条规则是否清楚、能否参与多个情境，以及玩家能否形成自己的计划。

## 你现在可以做什么

找一个具体片段，记下实况链接和时间点；不要急着总结整个游戏。描述玩家获得的能力、限制和关卡问题，再写下至少一种可能解法。如果它让你困惑，也请把“没看懂的地方”留下来——那往往正是最值得讨论的部分。
