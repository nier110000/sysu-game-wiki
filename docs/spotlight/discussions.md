# 讨论记录

这里保存群内讨论和分享会中的关键问题。目标不是写会议流水账，而是留下观点如何发生变化。

## 记录模板

```md
# 讨论主题｜日期

## 参与者

## 我们带着什么问题开始？

## 讨论过的案例
- 案例与原始链接：
- 观察表对应行：

## 主要观点与分歧

## 讨论后形成的暂时共识

## 仍未解决的问题

## 下一步行动
- [ ] 需要补看的案例
- [ ] 需要做的原型
- [ ] 负责人和时间
```

## 建议节奏

每次选 3–5 个具体案例，提前让成员看对应片段。讨论时先复述事实，再提出解释；结束前确定一个能被原型验证的问题。会后把腾讯表格中的原始观察链接回整理后的 Wiki 页面。
