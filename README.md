# SYSU Game Wiki

中山大学游戏设计 / 开发小组的公开知识库。这里沉淀游戏案例观察、设计方法、开发与美术笔记、活动记录和项目复盘。

## 本地运行

```bash
npm install
npm run docs:dev
```

## 构建

```bash
npm run docs:build
```

静态文件输出到 `docs/.vitepress/dist`。

## 内容工作流

腾讯表格收集原始观察 → 群内讨论 → Wiki 整理案例 → 提炼设计规律 → 2D 原型 → GameJam → 复盘。

## 维护与投稿

网站管理员、内容审核者和组员请阅读 [《维护与投稿指南》](CONTRIBUTING.md)。指南包含网页修改、Wiki 投稿、图片管理、多人协作、审核与上线检查流程。
